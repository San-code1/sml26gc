# Contributing

The rules for changing this repository (code style, architecture, tests, git workflow,
language, licences) are in [`AGENTS.md`](AGENTS.md). They apply to everyone, people and coding
assistants alike. How to set up a computer, build and check the project:
[`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md).

You may work with any AI coding agent, or with none: a contribution is judged by its code, its
tests and how well it follows the rules, not by the tool that helped write it.
