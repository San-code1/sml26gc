An emulator that plays Super Mario Land 2: 6 Golden Coins from your own cartridge file, and a
level editor that makes edited copies of it (levels, objects, the world map, new zones).
No game is included: see NO-CARTRIDGE.txt.

Not affiliated with or endorsed by Nintendo.


STARTING

  {game}           plays the game, or a project made in the editor
  {editor}    edits levels, objects and the world map

The first time, either program asks for your Super Mario Land 2 - 6 Golden Coins (USA, Europe)
cartridge file (.gb); both then use it. The original file is only read, never changed.

Windows may say it protected your PC the first time a program runs (the programs are not
signed): choose "More info", then "Run anyway".

Nothing needs installing. Each program speaks the system's language until another is chosen
(English, Spanish, Japanese, Portuguese, French, German, Italian, Indonesian, Russian,
Simplified Chinese, Korean).


YOUR FILES

Everything the programs keep is written in this folder, next to them: settings
(settings.cfg, editor.cfg), the cartridge chosen (base_cartridge.txt), the editor's projects
(editor\projects), the games' saves (saves) and exported files (exports). Keep the folder
where you can write, such as Documents (not Program Files); the programs warn when they cannot.
To move or back up everything, move or copy the whole folder.


GAME KEYS (changeable in the pause menu)

  Arrows      move               X        A (jump)
  Z           B (run, fire)      Enter    Start
  Backspace   Select             Esc      pause menu
  F11         full screen        Left Ctrl (held)  fast forward

A game controller plays as soon as it is connected.
